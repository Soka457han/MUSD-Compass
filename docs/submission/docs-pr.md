**PR body:**

> Adds MUSD Compass, a Mezo Buildathon (Wave 1) project, to the Community Projects list. It reads sMUSD, the Stability Pool, Mezo pools, PriceFeed and borrow parameters on mainnet, and writes only on testnet (sMUSD deposit, claim, withdraw with exact-amount approvals). No custody and no contracts of its own.
